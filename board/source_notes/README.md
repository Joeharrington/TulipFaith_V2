# Source Notes

This folder is for short local framework notes that improve Board of Advisers answer quality.

These notes are not copied books, copyrighted source dumps, or replacement source libraries. Keep them concise, original, and citation-oriented.

Each note should include:

- Adviser seat
- Core works
- Key frameworks
- Useful decision rules
- Common misuses
- What the seat should answer
- What the seat should not answer
- Uncertainty notes
- Links or citations when useful

Do not add individual source note files until there is a specific need.
